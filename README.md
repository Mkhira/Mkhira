## 🧑‍💻 About Me

I'm a mobile engineer who has been shipping **Flutter** apps since 2019 and now builds production **React Native (Expo)** apps as well. I care about apps that stay maintainable as they grow, so most of my work is organised around **feature-first Clean Architecture, SOLID, dependency injection and tests**.

Lately I've been deep in **AI-assisted ("vibe") coding**: I don't just use tools like Claude Code, I build **skills, plugins and LSP integrations** for them so the agent generates layered, type-safe, tested code instead of ad-hoc snippets.

- 🔭 Currently building **ZATCA Mobile**, the Saudi Zakat, Tax and Customs Authority app, in **React Native (Expo) + TypeScript** with clean architecture, `tsyringe` DI, react-query, i18n (EN/AR, full RTL) and Jest.
- 🛠️ Maintaining open-source **Claude Code skills & plugins** for Flutter and React Native.
- 🌱 Exploring agent workflows, script-driven code generation and token-efficient prompting.
- 🌍 Bilingual apps are my specialty: Arabic/English UI, RTL layouts and Arabic text normalisation.
- 💬 Ask me about Flutter, React Native, Clean Architecture, Bloc/Riverpod, or getting real value out of coding agents.

| [**react-clean-architecture**](https://github.com/Mkhira/react-clean-architecture) | Claude Code agent skill that scaffolds a **complete clean-architecture feature** in a React Native (Expo) app from a single `curl` paste: DTOs, mappers, services, repositories, use cases, DI wiring, i18n, react-query and Jest tests. Also builds **pixel-accurate screens from Figma**, verified live on the iOS simulator. Deterministic Node scripts do the mechanical work, so it's accurate and token-cheap. | React Native · Expo · TypeScript · tsyringe · Jest · Figma MCP |

Codegen, 5 state-management stacks (Bloc, Riverpod, Provider, GetX, MobX), SDK-aware, and built on progressive disclosure so the agent only loads what the task needs. | Flutter · Dart · Bloc · Riverpod · Claude Code |
